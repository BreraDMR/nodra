# NORDRA

NORDRA is a fictional cycling equipment store built as a full-stack portfolio project. The React storefront and admin app consume a Symfony JSON API backed by PostgreSQL. All products, orders and imagery are demo material; the checkout never charges a card or arranges shipment.

The project is under construction. See [PLAN.md](PLAN.md) for milestones and [STATUS.md](STATUS.md) for the latest verified state.

## Repository layout

- `api/` — Symfony API, database migrations and fixtures
- `web/` — Next.js React storefront and admin
- `PLAN.md` — ordered implementation and acceptance plan

## Publication

This repository has no GitHub remote. It is intended for local review before a separate publication decision.
